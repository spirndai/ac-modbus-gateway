# ac-modbus-gateway

**不支持联网的中央空调，如何远程控制？——在总线上下手。**

![约克 MC2100 面板](docs/images/mc2100.png)

本方案针对约克（York）水系统中央空调（实测面板型号 **MC2100**，带 RS485 接口）：空调主机与各面板之间通过 RS485 Modbus RTU 总线通信，但厂家不提供（或高价提供）远程控制。我们在总线上并联一个 ESP32 网关，**监听**主机与面板之间的全部问答数据还原空调状态；需要控制时，在**总线空闲间隙**注入一帧标准 Modbus 写命令。Modbus RTU 帧中不存在发送者身份，协议层面没有来源校验，面板收到地址与 CRC 都合法的写命令即执行；实测确认这样下发的命令与人工操作面板效果完全一致，下一次主机轮询时面板正常上报新状态。

不改动空调主机与室内机、不碰厂家固件，原系统的通信完全不受影响。动手环节在面板上：数据可从面板背面预留的 RS485 口引出（不拆面板，需外接电源）；要省掉外接电源则可拆到面板内层引出 12V DC（见部署指南）。

> 本方案源于个人家庭使用（7 个面板），已稳定运行较长时间，命令注入策略经过实测验证。但它**不是工程化产品**，没有经过多环境验证，无法保证换个环境也能正常工作；作者也非空调/电子专业出身——请确认自己有足够的技术能力再尝试，接线错误、误触都可能烧毁设备，风险自担（见文末免责声明）。

## 方案特点

- **总线旁路，非侵入**：只并联监听总线；控制命令利用实测的总线空闲窗口注入，不影响原通信（空调设备和厂家固件不做任何改动）
- **采集**：开关机、运行模式（冷风/热风/换气/地暖/地暖热风）、设定温度、当前温度、风速、水泵状态
- **控制**：开关机、模式切换、设定温度、风速调节、水泵开关
- **协议逆向**：通过对比"面板操作 → 总线数据变化"还原寄存器含义（寄存器表见协议文档）
- **固件极简**：ESP32 只负责搬运原始帧（上报 + 空闲注入），解析、去重、存储全在服务器，改逻辑不用重烧固件
- **完整链路**：状态入库 PostgreSQL、手机网页查看与控制
- **自动寻址**：服务器从上报告包的源地址自动学习网关 IP（DHCP 变化无需配置），控制命令发回网关

## 架构

```
                     RS485 总线
      主机(主控) ◄───────┬────────► 面板（各自独立地址）
                       │
        并联监听（只读）+ 空闲时注入命令
                       │
                 ┌─────┴─────┐
                 │   ESP32   │  WiFi 网关 (firmware/)
                 └─────┬─────┘
          UDP:12333 上报│ ▲ UDP:12335 接收控制命令
                       ▼ │
                 ┌───────┴────┐     ┌────────────┐
                 │    svr     │────►│ PostgreSQL │
                 │ Modbus 解析 │     └────────────┘
                 │ 入库        │
                 └────────────┘
                 ┌────────────┐
                 │  websvr    │  浏览器/手机查看与控制
                 └────────────┘  （查数据库取状态，UDP 直发命令到网关）
```

## 快速开始

```bash
# 服务器（改 docker-compose.yml 里的 your_db_password）
cd server && docker compose up -d

# 固件：Arduino IDE 打开 firmware/udp_to_modbus/udp_to_modbus.ino
# 修改顶部 WiFi / 服务器地址 / OTA 密码后编译烧录
```

浏览器访问 `http://<服务器IP>:9950` 查看和控制。详细步骤见 [docs/deployment.md](docs/deployment.md)。

> **语言说明**：文档为中文，Web 界面与消息文案也是中文。如需其他语言，建议直接把模板和字符串交给 AI（如 Claude）转换成你的语言——比给项目内建多语言机制更简单直接。
